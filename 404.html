Universal Unit System converter

Write a request of the UUS API; the answer is computed in this page from units.json.

Examples: 9E0*harmon/foot_TRAD speed acceleration, all units 0 °C in °F magnitude 3 Omega_1 harmon
How to write a request (the full specification) 
REQUEST    ::= ( UNITS | CONVERSION ) [ "." TYPE ]
CONVERSION ::= QUANTITY "/" ( QUANTITY | "*" )          "*": every unit of the dimension
QUANTITY   ::= [ VALUE ( "*" | "°" | "@" ) ] UNITS
UNITS      ::= UNIT [ POWER ] { UNIT [ POWER ] }         harmon1nic-1, Omega_1nic-1
UNIT       ::= NAME { "_" ( NAMESPACE | VARIANT ) }      meter_SI, meter_universal  (SI/meter is the same)
NAMESPACE  ::= SI | TGM | IDUS | TONAL | TRAD | CGS | CONST
VARIANT    ::= harmonic | universal | GCD | gravitic | exact
VALUE      ::= NUMBER12 ( "E" | "Z" ) [ "-" ] NUMBER     E: decimal, Z: duodecimal (digits x e)
The digits of VALUE set the precision of the answer.
